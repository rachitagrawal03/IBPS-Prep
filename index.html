Three-stage selection: Prelims (qualifying only) → Mains (80% of final score) → Interview (20% of final score). Prelims scores are NOT counted in final merit — focus maximum energy on clearing Prelims quickly and dominating the Mains IT paper.

DBMS — Detailed Syllabus

⭐ DBMS is the single most important topic — 15–18 questions. This is where toppers differentiate. Cover every sub-topic below thoroughly.
RDBMS Concepts & Keys
~3–4 Qs
HIGH
  • Primary Key, Foreign Key, Candidate Key
  • Composite Key, Super Key, Alternate Key
  • Referential integrity constraints
  • ER Diagrams: entities, attributes, relationships
  • Cardinality: 1:1, 1:N, M:N
SQL Queries
~4–5 Qs
HIGH
  • DDL: CREATE, ALTER, DROP, TRUNCATE
  • DML: SELECT, INSERT, UPDATE, DELETE
  • DCL: GRANT, REVOKE
  • TCL: COMMIT, ROLLBACK, SAVEPOINT
  • Joins: INNER, LEFT, RIGHT, FULL OUTER, CROSS
  • GROUP BY, HAVING, ORDER BY
  • Subqueries, correlated subqueries
Normalization
~3–4 Qs
HIGH
  • 1NF: atomic values, no repeating groups
  • 2NF: 1NF + no partial dependency
  • 3NF: 2NF + no transitive dependency
  • BCNF: every determinant is candidate key
  • 4NF: no multi-valued dependency
  • Identify anomalies (insertion/update/deletion)
Transaction Management
~2–3 Qs
MEDIUM
  • ACID: Atomicity, Consistency, Isolation, Durability
  • Concurrency control: Locking (Shared/Exclusive)
  • Two-Phase Locking (2PL)
  • Deadlock in transactions
  • Transaction states: Active, Committed, Failed, Aborted
Advanced DBMS
~2–3 Qs
MEDIUM
  • Database Triggers (BEFORE/AFTER; row/statement)
  • Implicit vs Explicit Cursors
  • Stored Procedures & Functions
  • Sequences and Indices (CREATE INDEX)
  • Data Dictionary / System Catalog
  • Database Administration concepts
Control Structures in SQL
~1–2 Qs
LOW
  • IF-THEN-ELSE in PL/SQL
  • LOOP, FOR LOOP, WHILE LOOP
  • Exception handling in PL/SQL

M-08

Computer Organisation & Microprocessor

CO

Computer Organisation & Microprocessor Concepts

LOW-MED · 3–5 Qs

Number Systems & Codes: Binary, Octal, Hexadecimal conversions. BCD, Gray code, ASCII, Unicode. Binary arithmetic (addition, subtraction using 1's complement, 2's complement). Floating point representation (IEEE 754).

Logic Gates & Boolean Algebra: AND, OR, NOT, NAND, NOR, XOR, XNOR gates. Truth tables. De Morgan's theorems. Boolean simplification using K-maps (Karnaugh maps). Combinational circuits: adder, multiplexer, decoder, encoder.

CPU Architecture: ALU, Control Unit, Registers (PC, MAR, MDR, AC). Instruction cycle (Fetch-Decode-Execute). Instruction types and addressing modes (immediate, direct, indirect, register, indexed). Pipeline stages and hazards (structural, data, control).

Memory Hierarchy: Registers → Cache (L1/L2/L3) → RAM → Secondary storage. Cache mapping: Direct, Associative, Set-Associative. Cache replacement policies (LRU, FIFO). ROM types: PROM, EPROM, EEPROM, Flash.

Microprocessor Basics: 8085 architecture (data bus, address bus, control bus). Interrupts (TRAP, RST 7.5, RST 6.5, RST 5.5, INTR). 8086 vs 8085 differences. DMA, I/O interfacing basics.

STR

Exam Strategy

Three-phase master plan: Weeks 1–3 clear Prelims (English + Reasoning + Quant). Weeks 4–7 dominate Mains IT PK — DBMS is your highest-value investment. Week 8 mock tests + revision. Final merit = Mains 80% + Interview 20% — the IT paper is everything.

📌 Phase 1 — Prelims Clearing (Week 1–3)

  • Quant: DI (bar/pie/table), Number Series, Quadratic Equations, Simplification, Arithmetic (SI/CI, P&L, TSD, Work)
  • Reasoning: Puzzles + Seating Arrangement (2–3 sets daily), Syllogism, Inequalities, Input-Output, Coding-Decoding
  • English: RC passages daily, Error Spotting rules, Cloze Test, Para Jumbles
  • Attempt 1 full Prelims mock from Week 2 onwards — strict 120-min timing, 3 sections
  • Prelims is qualifying only — clear all 3 sectional cut-offs, then move on

📌 Phase 2 — Mains IT Deep Dive (Week 4–7)

  • Week 4 — DBMS (your gold mine): SQL (write queries daily), Normalization 1NF–BCNF, ER diagrams, Keys, Triggers, Cursors, ACID properties
  • Week 5 — Networks + OS: Memorise OSI layers daily, subnetting, all port numbers; OS scheduling Gantt charts, deadlock Banker's algorithm, page replacement
  • Week 6 — SE + OOP: All 7 SDLC models (when to use which), testing types, UML diagrams, OOP pillars with Java examples, cyclomatic complexity
  • Week 7 — DSA + CO + Revision: Data structure operations, sorting complexities, number system conversions, logic gates; full DBMS revision
  • 20 IT MCQs from previous papers daily throughout Phase 2

📌 Phase 3 — Mock Tests + Final Revision (Week 8)

  • Full IT PK mock tests (60 Qs in 45 min strict) — every alternate day
  • Analyse: categorise each wrong answer — knowledge gap or careless mistake
  • Revise cheat sheets: SQL syntax, normalization rules, OSI layers, algorithm complexities
  • Banking IT topics for interview prep (CBS, RBI regulations, NPCI, payment systems)
  • ~45 seconds per question in IT paper — build this reflex through practice

✅ Do This

  • Write SQL queries by hand — syntax sticks better
  • Draw OSI layers from memory every morning
  • Prioritise DBMS above all other IT topics
  • Solve PYQ papers (2019–2024) — repeating patterns exist
  • Guess only when 2 options clearly eliminated (−0.25 rule)
  • In Prelims: attempt Reasoning & Quant first (1 mark each)

❌ Avoid This

  • Over-investing in DSA (only 5–6 Qs) at cost of DBMS
  • Ignoring Computer Organisation (3–5 Qs — easy marks)
  • Blind guessing with −0.25 negative marking
  • Spending 3+ min on one MCQ in 45-min IT paper
  • Starting PYQ practice in the last week
  • Neglecting Software Engineering — it carries 7–9 questions

Exam Day Tips

⏱️
Prelims Timing

48 sec/question. Attempt Reasoning (50 marks, 1/Q) and Quant (50 marks, 1/Q) first. English last (25 marks, 0.5/Q).

🎯
Mains Timing

45 seconds per IT question. Start with DBMS and Networks — your strongest zones. Leave Computer Organisation for last.

📊
Negative Marking Rule

Guess only when you can eliminate 2+ options. Random guessing = expected loss (3 wrong × −0.25 = −0.75 per 4 attempts).

📝
Sectional Cut-offs

All 3 Prelims sections have independent cut-offs. 89/90 in 2 sections doesn't compensate for 0 in the third.

🧠
Interview Mindset

Know your IT concepts cold. Admit if you don't know — don't bluff. Prepare a 2-minute "tell me about yourself" with tech highlights.

✅
Documents

Carry Admit Card + original photo ID + 2 passport photos. Check exam centre location night before. Reach 30 min early.

📖 RC Strategy Notes Reading Comprehension · Prelims Strategy
01 Strategic Time Management
▸
Time Allocation: Aim to complete an RC passage within 5 to 7 minutes for Prelims.
▸
Question Order: Tackle questions in this sequence for maximum efficiency:
①
Vocabulary-based questions first
②
Direct keyword-based questions
③
"True / False" statement questions
④
Inference-based questions last
02 Approaches for Different RC Types
▸
Long Non-Story Based Passages — Most common in Prelims:
Step 1: Read the questions first (not the passage). Identify keywords — numbers, names, specific terms.
Step 2: Skim the passage — do not read every word. Focus on locating the keywords you identified.
Step 3: Only read the specific lines containing keywords in detail to find your answers.
▸
Short Passages — Common in Mains:
Do not skip to questions. Perform a detailed reading of the full passage first to understand context and nuances.
▸
Story-Based Passages — Rare but simple:
Read the story completely, then answer questions. No skimming needed.
03 Mastering Skimming
▸
What to Ignore: Skip data-heavy sections, lengthy examples, and unclear sentences. Your goal is to build a mental map or "Main Idea" of the passage — not full comprehension.
▸
Keyword Matching: The moment you spot a keyword while skimming, immediately switch to detailed reading for that specific section only.
💡 Think of skimming like radar: you sweep broadly until you get a signal (keyword), then you zoom in — not before.
04 Vocabulary & Context Clues
▸
Contextual Meaning: If you don't know the exact meaning of a word, use the tone of the sentence (positive or negative) to eliminate wrong options.
▸
Example from Video: The phrase "Bad Blood" carries a negative tone → correct answers were "Ill-feeling" or "Enmity", not a positive option.
🎯 Tone method: Even without knowing the word, ask — is this phrase positive, negative, or neutral? This eliminates at least 2 options instantly.
05 Key Concepts to Remember
▸
Inference vs. Fact: Direct questions are answered verbatim from the text. Inference questions require understanding what is implied — the answer won't be stated word-for-word.
▸
Avoid "Keyword Traps": Options may contain your keyword but in a completely different context. Always verify meaning, not just word presence.
⚠️ Classic trap example: "Anti-terrorist" vs "Anti-India terrorist" — both contain the keyword, but mean very different things. Read the option fully before selecting.
